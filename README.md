# Estudio Sculpt & Fuerza

Planificador y guía en vivo para tres clases distintas — **Sculpt** (fluida, sistema de 9, termina en core), **Fuerza** (por patrón de movimiento, series con descanso, termina en cardio) y **Barre** (ballet, pulsos en 8, termina estirando).

Incluye:
- Generador de rutinas (~230 ejercicios), variedad garantizada clase a clase.
- Vista Instructor a pantalla completa con metrónomo / temporizador de descanso.
- Retroalimentación de clase que ajusta las próximas rutinas.
- Programas de progresión semanal (intensidad escalada, no solo variedad).
- Biblioteca musical con BPM real + brief de playlist por bloque para Spotify.
- Acceso privado (Supabase Auth) — solo la instructora puede entrar.

Single-file app (`index.html`), sin framework ni build. Vivo en: https://salvarezdelfin-glitch.github.io/sculpt-fuerza/
